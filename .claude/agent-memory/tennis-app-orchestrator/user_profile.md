## 역할 및 배경

- 이 프로젝트의 sole developer이자 운영자
- 테니스 클럽을 실제로 운영하며 직접 사용하는 앱
- 코드에 직접 깊이 관여함 (단순 지시자가 아님)
- 새로운 AI/개발 트렌드에 관심 많음 (하네스 기법 등 능동적으로 탐색)

## 협업 스타일

- 요청이 간결함 — "이거 해줘" 형태로 직접 지시
- 설명보다 결과 우선 선호
- 트레이드오프 설명은 환영하되, 너무 길면 부담스러워함
- 새 기법/도구를 제안하면 관심 갖고 적용 원함

## 커뮤니케이션

- 한국어로 대화
- 코드는 영어, 설명은 한국어
- 질문에 답할 때 너무 장황하지 않게
